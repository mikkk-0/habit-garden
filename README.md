# Сад привычек

Локальное приложение для ежедневных привычек: карточки заданий, календарь отметок, стрики, архив и напоминания. Есть настольная версия для Linux и отдельная [версия для Android](mobile/android/README.md). Данные каждого устройства остаются на нём; синхронизации между устройствами пока нет. После закрытия окна настольное приложение остаётся в системном трее и продолжает показывать напоминания.

## Запуск на Linux

Нужны Linux, Python 3.10+ и `notify-send` для системных уведомлений. Склонируйте репозиторий и запустите приложение:

```sh
git clone git@github.com:mikkk-0/habit-garden.git
cd habit-garden
./run.sh
```

При первом запуске `run.sh` создаёт окружение `.venv` и устанавливает PySide6. Повторный запуск открывает уже работающий экземпляр. Закрытие окна оставляет приложение в трее; значок трея открывает окно, позволяет создать задание или полностью выйти. Чтобы закрыть приложение из терминала:

```sh
./run.sh stop
```

Добавить приложение в меню программ:

```sh
./install-desktop.sh
```

Если нужны напоминания сразу после входа в систему, используйте `./install-desktop.sh --autostart`. Автозапуск поднимает приложение в трее без открытия окна.

Интерфейс также доступен локально по адресу <http://127.0.0.1:8765> во время работы приложения.

## Использование

- ЛКМ по карточке отмечает сегодняшний день выполненным; СКМ снимает отметку; ПКМ открывает календарь и настройки.
- За ручку `⠿` карточку можно перетащить на новое место. Когда ручка в фокусе, стрелки тоже меняют порядок.
- Кнопка `···` открывает календарь и настройки также на ноутбуках и сенсорных экранах. В календаре можно изменить любой день от создания задания до сегодня.
- Эмодзи задания показывает выполнение сегодня: приглушённое до отметки и цветное после. Его можно выбрать при создании и поменять позже. В меню выбора есть категории и поиск по русским названиям и словам.
- Стрик показывает дни подряд до сегодня, если сегодня выполнено, иначе до вчера. Процент считается по всем дням от создания включительно.
- Время напоминания задаётся отдельно для каждого задания (по умолчанию 20:00). Уведомление приходит раз в день, если к назначенному времени задание не выполнено. Если приложение запущено позже назначенного времени, пропущенное за сегодня напоминание приходит после запуска.
- Архивные задания сохраняют историю, но не участвуют в ежедневном счётчике и напоминаниях. Их можно восстановить.

База данных: `~/.local/share/habit-garden/habits.db` (или путь из `HABIT_GARDEN_DB`). На каждый выполненный день хранится одна компактная запись; пустые дни в базе не занимают место. Порядок карточек хранится **отдельно от базы** в `~/.config/habit-garden/order.json` (или по пути из `HABIT_GARDEN_ORDER`). Журнал приложения: `~/.local/share/habit-garden/app.log`.

Планировщик ждёт ближайшего напоминания и просыпается при изменении задания; он не опрашивает базу постоянно.

## Тесты

```sh
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -v
```

Для дальнейшей разработки есть [карта проекта](docs/DEVELOPMENT.md): компоненты, схема данных, API и порядок изменений.

Код настольной версии разделён на расчёты (`domain.py`), хранилище (`db.py`), напоминания (`reminders.py`), локальный API (`server.py`) и интерфейс (`static/`). Android-приложение находится в `mobile/android` и использует те же правила расчёта на Kotlin; синхронизацию понадобится спроектировать отдельно.

Эмодзи и их порядок взяты из [Unicode Emoji 18.0](https://www.unicode.org/Public/emoji/latest/emoji-test.txt), русские названия и слова поиска — из [Unicode CLDR 49](https://github.com/unicode-org/cldr/blob/release-49/common/annotations/ru.xml). Каталог хранится локально в `src/habit_garden/static/emoji-catalog.json`, поэтому для выбора эмодзи интернет не нужен. Чтобы обновить каталог из официальных источников, запустите `python3 scripts/build_emoji_catalog.py`. Условия лицензии перечислены в `THIRD_PARTY_NOTICES.md`.
