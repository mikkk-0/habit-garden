# Сад привычек

Локальное настольное приложение для ежедневных привычек. Данные остаются на компьютере. Интерфейс открывается в отдельном окне Chrome/Chromium; сервер и напоминания продолжают работать в фоне после закрытия окна.

## Запуск

Нужны Python 3.10+ и Linux с `notify-send` для системных уведомлений. Дополнительных Python-библиотек нет.

```sh
./run.sh
```

Повторный запуск открывает новое окно с уже работающим приложением. Чтобы остановить фоновый процесс:

```sh
./run.sh stop
```

Добавить приложение в меню программ:

```sh
./install-desktop.sh
```

Если нужны напоминания сразу после входа в систему, используйте `./install-desktop.sh --autostart`. Автозапуск поднимает только фоновую часть, без открытия окна.

Если браузер не открылся автоматически, адрес приложения: <http://127.0.0.1:8765>.

## Использование

- ЛКМ по карточке отмечает сегодняшний день выполненным; СКМ снимает отметку; ПКМ открывает календарь и настройки.
- Кнопка `···` открывает календарь и настройки также на ноутбуках и сенсорных экранах. В календаре можно изменить любой день от создания задания до сегодня.
- Стрик показывает дни подряд до сегодня, если сегодня выполнено, иначе до вчера. Процент считается по всем дням от создания включительно.
- Время напоминания задаётся отдельно для каждого задания (по умолчанию 20:00). Уведомление приходит раз в день, если к назначенному времени задание не выполнено. Если приложение запущено позже назначенного времени, пропущенное за сегодня напоминание приходит после запуска.
- Архивные задания сохраняют историю, но не участвуют в ежедневном счётчике и напоминаниях. Их можно восстановить.

База данных: `~/.local/share/habit-garden/habits.db` (или путь из `HABIT_GARDEN_DB`). На каждый выполненный день хранится одна компактная запись; пустые дни в базе не занимают место. Журнал приложения: `~/.local/share/habit-garden/app.log`.

Планировщик ждёт ближайшего напоминания и просыпается при изменении задания; он не опрашивает базу постоянно.

## Тесты

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Код разделён на расчёты (`domain.py`), хранилище (`db.py`), напоминания (`reminders.py`), локальный API (`server.py`) и интерфейс (`static/`). Это позволит позже использовать тот же API и модель данных в мобильном клиенте.
