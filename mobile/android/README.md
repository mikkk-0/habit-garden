# Сад привычек для Android

Нативное приложение для Android 8.0+ повторяет основные действия настольной версии: создание и редактирование заданий, отметки в календаре, стрик и процент, архив, выбор эмодзи из локального каталога, собственное время напоминания и произвольный порядок карточек. Данные телефона хранятся только на телефоне. Синхронизации с компьютером пока нет.

## Сборка и запуск

1. Откройте эту папку (`mobile/android`) в Android Studio.
2. Установите Android SDK Platform 36 и SDK Build Tools 36 через SDK Manager, если Studio предложит.
3. Дождитесь синхронизации Gradle и запустите конфигурацию `app` на телефоне или эмуляторе с Android 8.0+.

Из терминала с настроенным `ANDROID_HOME`:

```sh
./gradlew testDebugUnitTest assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Это отладочная сборка; для публикации потребуется отдельная подпись релизной сборки.

## Напоминания

- Android хранит отдельный системный будильник для каждого активного задания. После срабатывания приложение ставит будильник на следующий день. Постоянного фонового процесса, опроса базы и службы переднего плана нет.
- Удаление приложения из списка недавних **обычно не отменяет** эти будильники: Android запускает приёмник уведомления, когда наступает срок. После перезагрузки телефона, изменения часов, часового пояса и обновления приложения будильники восстанавливаются.
- Android 13+ запрашивает разрешение показывать уведомления. На Android 12+ приложение предлагает разрешение на точные будильники. Без него используется экономный системный будильник с возможной задержкой, которую определяет Android. Даже точный будильник при энергосбережении может немного сдвинуться.
- Принудительная остановка через системные настройки, отключённые уведомления или ограничения прошивки на фоновую работу могут остановить доставку до следующего открытия приложения. Приложение не обходит системные ограничения.
- Если задание выполнено до назначенного времени, уведомление за этот день не показывается. Если приложение открылось уже после времени напоминания, пропущенное за сегодня уведомление планируется вскоре после открытия. Повтора за один день нет.

## Данные и порядок

SQLite в приватном каталоге приложения хранит задания и только выполненные даты. Дни без отметки не создают строк. Порядок карточек хранится **отдельно от базы** в `SharedPreferences` как список ID; новый телефон получает собственный порядок. В архиве и активном списке порядок общий. Для перемещения зажмите `⠿` и перетащите карточку или нажмите `⠿` и выберите команду.

Код расчётов и правил напоминаний отделён от Android UI. Краткая [карта компонентов](../../docs/DEVELOPMENT.md) описывает оба приложения. Эмодзи берутся из того же локального Unicode/CLDR каталога, что и в настольной версии; интернет для выбора не нужен.
